# Exercícios de Análise de Dados — Preços de Combustíveis no Brasil

Exercícios práticos de análise de dados utilizando Python, Pandas e NumPy a partir de uma série histórica de preços de combustíveis no Brasil entre 2000 e 2021.

O projeto foi desenvolvido para praticar manipulação, tratamento, cruzamento e análise de dados, além do trabalho com séries temporais.

---

## Sobre o projeto

Este repositório reúne exercícios realizados a partir de dados reais do mercado brasileiro de combustíveis.

O objetivo principal foi praticar operações comuns em análise de dados utilizando Pandas e NumPy, trabalhando desde a união e organização dos arquivos até a extração de informações por período, estado e região.

Durante os exercícios foram explorados filtros, agrupamentos, séries temporais, cálculos de variação e operações entre diferentes conjuntos de dados.

---

## Tecnologias utilizadas

- **Python 3**
- **Pandas** — tratamento, manipulação, agrupamento e análise dos dados
- **NumPy** — operações numéricas e vetorização
- **Jupyter Notebook** — desenvolvimento e documentação dos exercícios
